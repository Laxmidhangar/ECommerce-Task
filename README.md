# Mini E-Commerce Store (MERN Stack)

A full-stack Mini E-Commerce application built using Node.js, Express, MongoDB, and React (Vite).

---

## 🚀 Features

- **Product Listing:** Fetch and display products dynamically from MongoDB.
- **Add Product Form:** Form validation for Name, Price (>0), and Image URL before submission.
- **Shopping Cart:** Real-time quantity management and automatic total price calculation using `reduce()`.
- **UI & Error Handling:** Proper loading states, clear error messages, and clean CSS layout.

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite), Axios, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose ODM
